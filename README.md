# BlueRoof WP Theme

### A clear, modern website concept for roofing companies

![BlueRoof WP Theme desktop preview](screenshots/desktop.png)

[Open the live design preview](https://rawpowered.github.io/BlueRoof-WP-Theme-Showcase/) · [View the mobile screenshot](screenshots/mobile.png) · [Contact the creator](https://github.com/RawPowered)

BlueRoof WP Theme presents roofing services in plain language. The homepage moves from the first decision to service options, roof materials, the work process, common questions, and an estimate request.

## Design highlights

| Area | Approach |
| --- | --- |
| First screen | Large roof photography, direct headline, clear estimate and exploration paths |
| Navigation | Centered wordmark, split desktop menu, compact scroll state, mobile menu |
| Services | Inspection, repair, replacement, and maintenance sections |
| Roof materials | Asphalt shingle, clay tile, concrete tile, metal, and low-slope visuals |
| Readability | Large type, measured line lengths, strong contrast, generous spacing |
| Performance | Responsive WebP hero, lazy-loaded supporting images, one stylesheet, small deferred script |

## WordPress foundation

The private development package is a custom classic WordPress theme. It includes page, post, archive, search, comment, sidebar, and 404 templates, plus logo support, menu locations, a Customizer header action, and a roofing homepage pattern. The public preview is static HTML generated from the theme's homepage pattern. It demonstrates the design without processing contact information.

## Release stage

This is version `0.1.0`, a design and development candidate. It is available to review with prospective clients. A clean WordPress integration test, block editor refinement, accessibility review, translation pass, image rights review, name clearance, and marketplace checks are planned before a commercial release. It has not been approved by ThemeForest.

The preview contact form is disabled and stores no information. The screenshots and design assets are shown for evaluation; no reuse license is granted through this showcase repository.
